# 국가 확장 요건

출력 계약은 세 나라가 공통이다. 그러나 계약이 같다고 결과가 생기지 않는다.
인과 국가 모델이 없는 나라는 `not_implemented`이며 현재 국면을 만들지 않는다.

국가 간 수혜 판단은 이 층에서 하지 않는다. 각 나라는 자기 공식 국면만 낸다.

## US — `implemented`

동결된 인과 모델이 있고 최신 수정치·엄격 ALFRED 검증을 모두 마쳤다. 단계 A-5의 실시간 침체 탐지 게이트는 통과하지 못했으며 그 판정은 유지된다.

모델 설정: `candidate_h_breadth_gate`

## KR — `not_implemented`

인과 국가 모델이 없다. 현재 국면을 만들지 않는다.

| 경제영역 | 후보 계열 | 붙이기 전에 확인할 것 |
|---|---|---|
| employment | 통계청 경제활동인구조사 취업자수 | 월간, 발표지연 확인, 계절조정, 수정 이력(빈티지) 확보 |
| income | 가계동향조사 실질소득 또는 국민계정 실질 GNI | 분기 계열은 주간 가교 규칙을 따로 정해야 한다 |
| production | 전산업생산지수 / 광공업생산지수 | 월간, 기준연도 개편 시 소급 수정 처리 필요 |
| consumption | 소매판매액지수 / 서비스업생산지수 | 월간, 명목·실질 구분 |
| claims | 고용보험 구직급여 신규신청자수 | 주간 가교로 쓰려면 주간 또는 월간 고빈도 확보 필요 |

## CN — `not_implemented`

인과 국가 모델이 없다. 현재 국면을 만들지 않는다.

| 경제영역 | 후보 계열 | 붙이기 전에 확인할 것 |
|---|---|---|
| employment | 도시조사실업률 / 도시 신규취업자수 | 월간, 계열 정의 변경 이력 확인 필요 |
| income | 주민 1인당 가처분소득 | 분기·누계 발표라 주간 가교와 누계 해제 규칙이 필요하다 |
| production | 규모이상 공업부가가치 증가율 | 월간, 1~2월 합산 발표 처리 필요 |
| consumption | 사회소비재 소매총액 | 월간, 1~2월 합산 발표 처리 필요 |
| claims | (직접 대응 없음) | 주간 가교 대체 지표를 별도로 정의해야 한다 |

## 공통 요건

어느 나라든 다음이 갖춰져야 인과 모델을 만들 수 있다.

1. 다섯 경제영역을 덮는 월간 이상 빈도의 계열
2. 계열별 실제 발표지연(달력 기준)
3. 수정 이력(빈티지). 없으면 실시간 검증을 할 수 없다
4. 표준화에 쓸 최소 10년 이력
5. 공식 침체 판정 기준일. 없으면 재현율·오탐률을 계산할 수 없다

다섯 번째가 특히 제약이다. 미국의 NBER에 해당하는 공식 기준일이 없는 나라에서는
성능 지표의 의미가 달라지며, 그 사실을 결과에 명시해야 한다.
