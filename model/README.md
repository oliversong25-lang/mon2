# 미국 경기국면 모델 v0.1

미국 실물경기의 주간 잠재 수준 `Y`와 최근 모멘텀 `X`를 추정해 12개 경기국면의
필터링 확률과 대표 국면 하나를 출력하는 독립 연구 모델입니다. 기존 AssetFlow
프런트엔드와 결합하지 않으며 `model/` 안에서 설치·실행·테스트됩니다.

## 모델의 목적과 12개 국면

`Y`는 고용·소득·생산·소비·판매에서 추출한 추세 대비 공통 실물경기 수준이고,
`X`는 `Y_t - Y_{t-4}`와 상태공간모형의 국소 기울기를 각각 과거 자료로 표준화해
평균한 모멘텀입니다. `atan2(Y, X)`의 0~360도 각도를 설정 가능한 30도 구간으로
나눕니다.

| 각도 | 대표 국면 |
|---:|---|
| 270~300 | 회복기 초기 |
| 300~330 | 회복기 중기 |
| 330~360 | 회복기 말기 |
| 0~30 | 확장기 초기 |
| 30~60 | 확장기 중기 |
| 60~90 | 확장기 말기 |
| 90~120 | 후퇴기 초기 |
| 120~150 | 후퇴기 중기 |
| 150~180 | 후퇴기 말기 |
| 180~210 | 침체기 초기 |
| 210~240 | 침체기 중기 |
| 240~270 | 침체기 말기 |

각도 관측확률은 원형 Gaussian이라 경계에서 0과 1로 끊기지 않습니다. 원점 거리
`R = sqrt(X² + Y²)`가 작으면 분포를 넓힙니다. 유지·다음·이전 상태를 우대하는
순환 전이행렬로 forward filtering하며 미래 관측을 쓰는 backward smoothing은 하지
않습니다. 각도 구간과 전이확률은 `configs/transitions.yaml`에서 바꿉니다.

## 경기 본체와 선행 레이어

경기 본체는 `PAYEMS`, `W875RX1`, `INDPRO`, `CMRMTSPL`, `RRSFS`, `ICSA`,
`CCSA`만 사용합니다. 영역 초기 비중은 고용 25%, 생산 20%, 소득 20%, 소비·판매
20%, 주간 브리지 15%이며, 개별 지표·영역 상한과 가용 지표 재정규화 규칙은
`configs/indicators.yaml`에 있습니다.

두 경기 수준 모델은 같은 희소 주간 사건 행렬을 받습니다.

- `CompositeFactorModel`: 제한된 신선도 기간 동안 마지막 신호를 보유하고 가용
  가중치를 재정규화하는 해석 가능한 기준선입니다.
- `DynamicFactorModel`: `[level, slope]` 국소선형추세 상태와 지표별 결측 관측을 가진
  실제 Kalman filter입니다. 월간 발표가 없는 주에는 예측만 하고, 이전 월 값을 새
  관측처럼 반복 삽입하지 않습니다. v0.1은 계열별 loading과 잡음분산을 재추정하는
  완전한 대규모 DFM은 아닙니다.

`PERMIT`, `NEWORDER`, `AWHMAN`, `T10Y3M`, `ANFCI`는 현재 `Y`에 섞지 않는 선행
레이어 설정으로 분리했습니다. 13주 예측은 아직 보정되지 않았으므로 확률을
지어내지 않고 `forecast_13w.status = not_calibrated`를 출력합니다.

## 데이터 출처와 가용일

`FredCollector`는 FRED graph CSV 최신 수정치를 원자료 캐시에 저장합니다. 네트워크
실패 시 기존 캐시가 있으면 경고와 함께 사용하고, 캐시도 없으면 실패합니다. API 키와
인증정보는 저장하지 않습니다. `FRED_API_KEY` 자리만 `.env.example`에 남겨 향후 공식
API·ALFRED 수집기를 같은 인터페이스에 붙일 수 있게 했습니다.

로컬 입력은 통합 `observations.csv` 또는 지표별 CSV를 지원합니다. 공통 스키마:

```text
indicator_id, observation_period, value, release_date, vintage_date,
fetched_at, source, revision_status, freshness_score
```

실제 `release_date`가 없으면 지표 설정의 보수적 지연일로 가용일을 추정하고 경고합니다.
FRED 최신 수정치에는 당시 빈티지가 없으므로 `vintage_date`는 비어 있을 수 있습니다.
원자료·가공자료·캐시는 각각 `data/raw`, `data/processed`, `data/cache`로 분리하며 Git에
포함하지 않습니다. 테스트는 재배포 제한이 없는 합성 데이터만 사용합니다.

```bash

# macOS/Linux: source .venv/bin/activate
```

```bash

```

FRED를 즉시 호출해 판정하려면 `--data-source fred`를 지정합니다. 네트워크 없이 전체
파이프라인과 보고서를 실행하는 방법:

```bash

```

```bash

  --start 1965-01-01 \
  --end 2026-08-14 \
  --walk-forward
```

## 출력 파일

`outputs/` 아래에 다음을 원자적으로 생성합니다.

확률은 남기되 `status = withheld`와 판정 보류 사유를 출력합니다.

## 백테스트와 미래정보 누출 방지

전처리는 현재 관측이 자기 기준분포를 바꾸지 않도록 한 칸 지연한 expanding 평균·표준
편차와 one-sided EMA를 사용합니다. 상태확률은 forward filter만 사용합니다. 한 번의
순방향 재귀가 매주 다시 적합하는 walk-forward와 같은 결과를 내므로 전체기간 그래프를
사후 smoothing한 것이 아닙니다.

테스트는 미래 구간을 10,000배로 바꾼 두 데이터셋의 과거 전체 판정이 완전히 같은지
비교합니다. 월간 지표의 비발표 주가 NaN 사건으로 남는지도 확인합니다.

NBER 기준일은 침체/비침체 포착률·오탐률에만 사용합니다. NBER에는 12개 세부국면
정답이 없으므로 12국면 정확도를 계산하지 않습니다.

> 본 결과는 최신 수정치 기준의 preliminary backtest이며, 당시 실제 공개정보만 사용한
> real-time vintage backtest가 아닙니다.

## 단계 A 강건성 재검증

`python -m business_cycle.validation.phase3`는 기존 설정, 원빈도 달력 3년 추세,
지표 성숙도, causal rolling median/MAD와 기여단계 Huber 제한을 순서대로 비교합니다.
원신호·제한 전 robust z·제한 후 신호를 함께 보존하고, MAD가 0이면 현재값을 제외한
과거 IQR과 표준편차 순으로 대체합니다. 지표는 이력 5년 미만이면 제외하고 5~10년은
가중치를 선형으로 늘리며, 이후에도 개별 20%·영역 30% 상한을 적용합니다.

2026-08-17 실자료 재검증에서 robust6 후보는 팬데믹 반응과 오탐률을 개선했지만
재현율·다단계 점프·3주 왕복 기준을 통과하지 못했습니다. 따라서 기본 설정은 변경하지
않았고 설정 스냅샷·해시를 만들지 않았으며 ALFRED도 시작하지 않았습니다. 측정값과
10개 차트는 `outputs/robustness_validation/phase3/`에 있습니다.

## 단계 A-2 corrected baseline

`configs/baselines.yaml`이 설정을 명시적으로 분리한다. `load_baseline(name)`으로 읽는다.

| 이름 | 추세 | 지표 표준화 | 성숙도 | robust | 좌표 표준화 |
|---|---|---|---|---|---|
| `legacy_benchmark` | 156주 고정 | expanding | 없음 | 없음 | expanding |
| `corrected_baseline` | 달력 3년 | 10년 rolling 평균·표준편차 | 5~10년 ramp | 없음 | expanding |
| `corrected_baseline_rolling_coordinates` | 달력 3년 | 같음 | 같음 | 없음 | 10년 rolling |
| `corrected_baseline_mature_coordinates` | 달력 3년 | 같음 | 같음 | 없음 | 10년 rolling, 최소 5년 |
| `corrected_baseline_full_maturity` | 달력 3년 | 같음 | 같음 | 없음 | 10년 rolling, 최소 10년 |
| `corrected_baseline_huber8` | 달력 3년 | 10년 rolling 중앙값·MAD | 같음 | Huber ±8 | expanding |

`legacy_benchmark`는 월간 지표에 156**개월**(약 13년) 추세를 적용하는 빈도 단위 문제를
그대로 갖고 있다. 이전 결과를 재현하기 위해서만 남겨 두며 운영 후보가 아니고, 재현율
93.4%를 복원해야 할 목표로도 쓰지 않는다.

```bash
python -m business_cycle.validation.phase4
```

2026-08-17 재검증에서 단계 A-2는 **미통과**다. 빈도 수정은 정상기 오탐을 크게 줄였지만
corrected baseline의 침체 재현율이 84.3%로 참고기준 85%에 못 미쳤고, 1985·1990 시작의
2001년 진입일 차이도 8주 기준을 만족하지 못했다. 설정을 동결하지 않았고 ALFRED도
시작하지 않았다. 측정값과 10개 차트는 `outputs/robustness_validation/phase4/`에 있다.

확인된 원인 두 가지를 함께 적어 둔다.

1. robust6은 단독으로는 해롭지 않다. 악화는 빈도 수정과의 상호작용에서 나온다.
   3년 추세를 원빈도에 적용하면 신호 절대값이 커지고 median/MAD 척도는 작아져 ±6
   제한이 훨씬 자주 걸린다.
2. 워밍업 의존성은 지표 전처리가 아니라 **좌표(X·Y) 표준화**에서 나온다. 지표 표준화에는
   5년 최소 이력 규칙이 있지만 좌표 표준화에는 26주뿐이었다. 그래서 1990 시작 실행은
   조용한 5년 표본으로 계산한 척도 0.25로 같은 합성요인을 Y = -4까지 부풀렸다.
   `coordinates(minimum_history_weeks=...)`로 최소 이력을 요구하면 차이가 44주에서
   21주로, 완전성숙 후 국면 불일치가 11.3%에서 2.4%로 줄어든다.

이 모델의 총 워밍업 요구는 지표 표준화 최소 이력 5년과 좌표 표준화 창 10년을 합쳐 약
15년이다. 1990년에 시작한 실행은 2005년에야 완전 성숙하므로 2001년 판정은 미성숙
판정이며, `corrected_baseline_full_maturity`는 그 경우 진입일을 아예 내지 않는다.

## 단계 A-3 좌표층

2차 표준화는 두 가지를 동시에 하고 있었다. 중심 재추정(시작시점 의존성의 출처)과
X·Y 척도 맞추기(각도 기하와 임계값이 의존하는 부분)다. 좌표 창 후보를 A(10년)·B(5년)·
C(3년)·D(7년)·E(재표준화 없음)로 비교한 결과 이 둘은 상충한다. 창을 줄이면 시작시점
차이는 사라지지만 중심이 최근 수준을 따라가 긴 확장기가 정상으로 보이고 오탐이 폭증한다.
층을 없애면 X가 Y보다 41% 작은 자연 단위가 그대로 남아 각도의 80%가 두 수직축에 몰리고
`phase_origin_scale`·`low_radius_jump_scale`·`phase_emission_sigma_degrees`가 의미를 잃는다.

여기서 도출한 구성이 `coordinate_f_scale_only`(척도 창 5년)와
`coordinate_g_scale_only_10y`(척도 창 10년)다. 합성요인은 평균 0인 표준화 신호의
가중평균이므로 중심을 이론값 0으로 고정하고 척도만 인과적으로 추정한다.

2026-08-18 재검증에서 단계 A-3은 **미통과**다. 지정 후보 A~E 중 기준을 모두 만족한 것이
없고, 후보 G는 필수 기준을 만족하지만 2001년 시작시점 차이가 한계값 8주에 정확히 걸리고
2020년 수축 판정이 앞당겨져 해당 구간 오탐이 13주 생긴다. 설정을 동결하지 않았고 ALFRED도
시작하지 않았다. 측정값과 10개 차트는 `outputs/robustness_validation/phase5/`에 있다.

성숙도 시계도 둘로 나눠 명시한다. 원자료 이력과 합성요인 이력이며, 상태는
`withheld` → `preliminary` → `official` 순으로 강하다. 보류가 잠정보다 강하고 모든
비공식 상태에 사유(`metadata.status_reason`)를 남긴다.

## 단계 A-4 운영 후보

`candidate_h_breadth_gate`가 단계 A-4를 통과했고 설정을 동결했다
(`outputs/robustness_validation/phase6/frozen_model_config.yaml`, SHA-256 동봉).

후보 G(중심 0 고정 + 10년 causal 척도)에 **영역 폭 확인 규칙** 하나만 더한 설정이다.
현재 침체는 여러 독립 경제영역이 동시에 나빠졌다는 판정이어야 하므로, 음수 영역이
최소 4개가 아니면 침체 관측확률을 인접 후퇴기로 넘긴다. 실업수당 두 계열은 같은
영역이라 폭 계산에서 한 번만 세어진다. 최소 4는 개발구간(1995~2012)의 실제 침체
주에서 관측된 최소 폭이며(2001년 4, 금융위기 5), 2020년은 임계값 선택에 쓰지 않았다.

```text
재현율 88.4%   오탐률 2.22%   정밀도 75.9%   F1 81.7%
다단계 점프 6건(미해명 0건)   3주 왕복 15   2022년 이후 오탐 0주
금융위기 확인 +5주   2020년 확인 +5주(시작 전 오탐 0주)
1985~1990 시작 2001년 확인일 범위 4주
```

## 단계 A-5 후보 H2와 정지

허용된 모델 수정은 한 번뿐이었다. 후보 H2를 만들어 두 게이트에 걸었고 **엄격 ALFRED
게이트를 통과하지 못했다.** 정지 규칙에 따라 H3를 만들지 않으며, 현재 설계에서 미국
v1 모델은 **채택하지 않는다**.

후보 H와 그 동결 파일·해시·보고서·ALFRED 결과는 실패한 검증 기록으로 `phase6`와
`phase7`에 그대로 보존한다. H2는 별도 설정 이름·별도 출력 디렉터리를 쓴다.

### 게이트를 바꾸기 전 진단

음수 영역이 정확히 3개인 주를 전부 감사했다. **개발구간(1995~2012)의 3영역 주 78개
가운데 공식 침체 주는 0개**이고, 같은 구간의 침체 주 113개는 모두 영역 4개 이상이었다.
"3영역인데 진짜 침체"라는 양성 사례가 개발 자료에 없으므로 임계값을 양성 사례에 맞출 수
없다.

### 후보 H2 설계

기본 규칙(영역 4개 이상)은 그대로 두고, 폭이 한 단계 모자란 주에만 걸리는 체계적 충격
예외를 더했다. 폭 임계값을 3으로 낮추지 않았고 팬데믹 날짜·분기·상수도 없다. 예외는
넓이 대신 **청구건수를 제외한 심각도**를 묻고, 최대 기여 지표·영역을 하나씩 빼도 그
심각도가 남는지 확인한다.

```yaml
minimum_core_negative_domains: 2
core_level: -2.93                  # 개발구간 비침체 주 최저 핵심수준 -2.9254
leave_one_indicator_level: -2.82   # 그 기준을 넘은 28주 중 가장 약한 값 -2.8174
leave_one_domain_level: -2.33      # 같은 구간 -2.3273
minimum_ungated_contraction_probability: 0.90
require_dynamic_agreement: true
```

임계값은 전부 1995~2012에서만 측정해 더 엄격한 쪽으로 반올림했다. 2013년 이후는 안정성
확인에만 썼다. "한 항목이 지배하지 않을 것"을 최대 점유율 0.5로 재지 않은 이유도
개발구간 통계로 남겼다 — 신호를 가진 핵심지표가 둘뿐이면 점유율 하한이 0.5라 구조적으로
충족 불가능하고, 개발구간 침체 주 113개 중 15개가 이미 0.5를 넘는다.

### 결과

```text

엄격 ALFRED 게이트 미통과
  4주 확인 +11주 (기준 +10주 이내)      미달
  공식 침체 8주 중 수축 판정 0주        미달
  예외 발동 0주 / 688주
```

2020년 실시간에서 예외가 발동하지 않은 이유는 자료 자체에 있다. 3/27의 붕괴는 신호의
95.8%가 실업수당이었고 ICSA 한 계열이 92.3%였다. 같은 주 핵심 동행지표만으로 잰 수준은
**+0.16으로 음수조차 아니었다**. 핵심 증거가 처음 나타난 4/17에도 한 지표를 빼면
심각도가 -3.56에서 -1.78로 무너진다. 공식 침체 구간 내내, 그 시점에 공개돼 있던 핵심
동행 자료는 넓고 한 항목에 기대지 않는 하락을 보여준 적이 없다.

### 판정 보류 10주 (2025-10-17~12-19)

지표는 7개 모두 있었고 **오래됐을 뿐**이다. 원인은 파이프라인 상태 논리도 특정 계열의
아카이브 구멍도 아니다 — 7개 계열 전부가 같은 창에서 새 빈티지를 내지 않았고, 매주
나오는 실업수당 두 계열까지 8주간 멈췄다. 원천의 발표 중단이다. 보류를 푸는 데 미래
정보가 필요하지 않았다. 정정 사항이 아니라 표시 정책 문제이며, 보류 주를 없애려고 H2를

## 경기국면 해석층

경제 모델은 그대로 두고, **이미 정해진 공식 국면을 설명하는 층**을 얹었다. 이 층은
국면을 다시 계산하지 않고 표시만 한다. 종목·섹터·비중·목표가·매매 판단을 만들지
않으며, 그런 필드가 출력에 들어오면 스키마 검증이 거부한다.

사용자의 투자 과정은 이렇다. 모델의 책임은 첫 칸에서 끝난다.

```text
경기국면 판정  →  사용자가 섹터·시장 해석  →  기업가치 평가  →  투자 결정
   (모델)                        (전부 사용자)
```

### 공식 국면은 언제나 하나

공식 국면은 인과 모델이 고른 승자다. 해석층은 모델 코드를 계약 표기로 옮길 뿐이다
(`_mid` → `_middle`). 경계에 걸려도 국면은 하나이며, `expansion 또는 slowdown` 같은
애매한 라벨은 검증에서 거부한다. 불확실성은 별도 필드로만 보인다.

### 세 가지 표시 규칙

| 규칙 | 임계값 | 어디서 나왔나 |
|---|---:|---|
| 경계 표시 | gap ≤ `0.1124` | 실제로 국면이 바뀐 주 211개의 1·2순위 차이 중앙값 |
| 전환 감시(지속) | Δ4주 ≥ `0.1667`, 4주 중 3주 상승 | 인접 국면 확률 4주 변화의 p90 |
| 전환 감시(단일) | Δ1주 ≥ `0.2315` | 같은 분포의 p99 |
| 확신도 약한 일치 | < `0.6516` | 합성–동적 일치도 분포의 p25 |

전부 1995~2026 최신 수정치 실행에서 측정한 값이며 사례를 보고 고르지 않았다. 근거
분포는 `boundary_policy.md`·`confidence_policy.md`에 있다.

**경계와 전환은 다른 질문이다.** 경계는 "지금 갈라져 있는가", 전환은 "옆 국면 쪽으로
여러 주에 걸쳐 밀리고 있는가"를 묻는다. 둘 다 공식 국면을 바꾸지 않는다.

### 경제영역과 산업은 다른 것

찬반은 대국면이 함의하는 좌표 사분면 부호로 정한다. 기여도 부호가 Y 부호와 같으면
수준이, 8주 변화 부호가 X 부호와 같으면 모멘텀이 뒷받침한다.

산업 폭은 **총량 지표에서 추론하지 않는다.** 필요한 7개 차원(고용 확산, 제조 대
서비스, 생산 시장군, 소비 업종, 건설·부동산, 수출 대 내수, 기여 집중도) 중 저장소에
있는 것이 0개이므로 `industry_breadth_status: not_available`,
`industry_concentration_status: not_measured`로 낸다.

### 패리티

해석층이 모델을 건드리지 않았다는 것은 기계로 확인한다. 공식 대국면·세부국면·12개
확률·X·Y·반지름·상태를 소수점 10자리로 정규화해 SHA-256으로 굳혔고, 1,650주 전부
일치한다. 값이 하나라도 달라지면 멈추고 원인을 찾는다 — 해시를 맞추려고 모델을
고치지 않는다.

### 국가

미국만 구현돼 있다. 한국·중국은 인과 모델이 없어 `not_implemented`이며 현재 국면을
만들지 않는다. 필요한 계열과 확인 사항은 `country_extension_requirements.md`에 있다.
국가 간 수혜 판단은 이 층에서 하지 않는다.

```bash
python -m business_cycle.interpretation.report
```

산출물은 `outputs/phase_interpretation/`에 있고 기존 phase6~8은 건드리지 않는다.

## 단계 A-7 현재상태 후보 I — 미채택

`slowdown_late`가 왜 나왔는지부터 진단했고, 그 결과가 예상과 달랐다.

### 진단 — 2026-08-14 판정은 현재 경제 상태의 판독이 아니다

leave-one-out 12건이 **전부** `slowdown_late`를 냈다. W875RX1을 빼면 Y가 −0.239에서
+0.053으로 뒤집히고, 소비 도메인을 빼면 각도가 `expansion_early` 구역을 가리키는데도
공식 국면이 움직이지 않았다.

원인은 상태필터의 저반지름 잠금이다. `low_radius_jump_constraint`는 반지름 < 0.75일 때
직전 국면의 인접 국면 밖 posterior를 **정확히 0으로** 만든다. 반지름은 2021-05-14부터
**275주 연속** 0.75 미만이었고, `slowdown_late`의 인접은 `slowdown_mid`와
`contraction_early`뿐인데 영역 폭 게이트가 `contraction_*`를 매주 0으로 만들었다.
나갈 문이 사라졌고 133주 동안 갇혔다.

같은 주 관측확률 1위는 `recovery_early`(0.607)였고 `slowdown_late`는 0.136이었다.
필터가 그 0.136에 98.5%를 줬다.

반증: 잠금만 끄면 2026 판정이 `recovery_early`로 바뀌고 **재현율·오탐률·F1이 완전히
동일하다**(0.884 / 0.0222 / 0.817). 잠금은 침체 탐지에 기여하지 않고 점프만 억제한다.

### 정규화 감사 — 척도조정은 원인이 아니다

CNP16OV·CLF16OV·IURSA로 척도조정판을 인과적으로 만들어 비교했다. 다섯 변형 모두
**최장 저반지름 연속이 정확히 275주로 동일**했고 F1은 전부 기준보다 낮았다.
`log_cycle`이 3년 단측 EMA 추세 대비 로그편차라 매끄러운 분모는 이미 추세에 흡수된다.
기존 변환을 유지하고, RRSFS·W875RX1·CMRMTSPL·INDPRO를 재디플레이트하지 않는다.

### X 척도 오염

Y 압축은 대체로 진짜다(로그 기준 89%가 분자). **X 압축은 전부 인공물이다** — 원신호는
16% 커졌는데 10년 rolling 척도가 **5.5배** 부풀었다. 2020년 모멘텀 급등이 창에 남아
2028년경까지 단위를 지배한다. 그래서 후보 I는 이 척도를 물려받지 않는다.

### 후보 I 설계

동결 설정 `configs/candidate_i.yaml`, SHA-256 `765e2ee6…`. 모든 값을 개발구간
(1995~2012)에서만 도출해 검증 전에 잠갔다.

- **모멘텀 척도**: 10년 인과 rolling MAD. 개발구간 비교에서 충격기 척도 상승 없음
  (0.944배), 2년 뒤 잔존 4.6%. rolling_std는 1.112/1.153, IQR 0.975/1.150,
  bounded_influence 1.095/1.228이었다.
- **도메인 우선 집계**: 5개 도메인 안에서 먼저 평균, 그다음 도메인 **중앙값**.
  두 계열 도메인이 두 배 발언권을 갖지 않고, 한 도메인이 총량을 끌고 갈 수 없다.
- **대국면**: (수준 부호, 모멘텀 부호) 네 조합. 각도·회전 없음. 침체는 동행 도메인
  4개 중 3개 이상을 요구하며 노동시장 스트레스는 동행 도메인이 아니다.
- **하위국면**: 각 대국면 안의 현재 심각도 진행도. 각도 구역이 아니다.
- **안정화**: 유계 여유 0.0212(개발구간 주간 점수차 변화 중앙값). 어떤 국면도 0이 되지
  않고, 점수 차이가 여유를 넘으면 그 주에 바뀐다. 강제 이탈 타이머 없음.

| 재현율 | **0.884** | **0.694** |
| F1 | **0.817** | **0.750** |

`slowdown_late`의 의미가 실제로 바뀌었다 — 후보 H에서는 모멘텀 −0.145로

동결 모델 후보 H는 그대로 운영 후보로 남는다. 다만 **2026-08-14 판정이 현재 경제

## 단계 A-8 후보 J — 미채택, 12국면 개발 중단

현재 상태를 먼저 바로잡는다.

- 후보 H는 **동결된 침체 탐지 벤치마크**다. 공식 현재국면 엔진이 아니다 —
  2026년 판정이 저반지름 경로 의존 잠금에 지배됐다.
- 후보 I는 기각됐다(재현율·F1 하락, 대형 점프 급증).
- 후보 J는 이 단계의 **마지막** 12국면 구조 후보였고, 잠근 게이트를 통과하지 못했다.
- **미국 v1 공식 현재국면 모델은 채택하지 않는다.**

### 후보 I의 중앙값 정보손실 진단

과제 가설과 자료가 일부 달랐다. 정확히 적는다.

- 모멘텀 중앙값이 **정확히 0인 주는 1,675주 중 1주**(0.06%)다. 2026-08-14가 그 한 주다.
  체계적 패턴이 아니라 드문 사건이었다.
- 진짜 문제는 다른 데 있었다. 중앙값은 총량 분산의 약 4분의 1을 잃고(수준 1.106 대
  등가중 평균 1.542), 등가중 평균과 **부호가 다른 주가 수준 9.2%·모멘텀 11.9%**이며,
  **25.0%의 주에서 그 주에 새 관측이 없던 도메인**의 값이 중앙값으로 뽑혔다.
- 그러나 국면 변경 385건 중 도메인 하나만 움직인 경우는 **0건**이고, 전이 387건과
  3단계 이상 점프 94건 중 모멘텀 중앙값이 0이던 주는 **0건**이다.
  **중앙값은 대형 점프의 원인이 아니었다.**

### 후보 J의 세 가지 통합 수정

동결 설정 `configs/candidate_j.yaml`, SHA-256 `a0d875268f1d720a…`. 모든 값을
개발구간(1995~2012)에서만 도출해 검증 전에 잠갔다.

1. **유계 등가중 총량** — 도메인 안에서 먼저 평균, 그다음 개발구간 p99 상한(수준 3.7763,
   모멘텀 3.7547)으로 자른 뒤 등가중 평균. 다섯 도메인이 모두 살아 있고, 한 도메인이
   총량을 끌고 갈 수 없으며, 여러 도메인이 함께 극단이면 총량도 상한까지 간다.
2. **계층 분류** — 대국면 4개를 먼저 고르고 그 안에서만 하위국면 3개가 경쟁한다.
   침체는 후보 I의 연접 규칙 대신 **연속 증거 점수의 두 경로**(넓은 수준 / 급속 악화)로
   판정하며, 어느 경로도 노동시장 스트레스만으로 성립하지 않는다.
3. **거리 인식 소프트 필터** — 순환 거리로 감쇠하되 **모든 성분이 양수**인 전이행렬.
   모수는 셋뿐이다(lambda_major 1.5, lambda_subphase 1.5, epsilon 0.01).

구조 게이트는 모두 통과했다 — 12국면 전부 도달, 최소 대국면 점수 1e-6 > 0, 전이행렬

§14-C에 따라 엄격 ALFRED는 돌리지 않았다.

### 왜 실패했는가

**재현율 상한은 정의에서 나온다.** 개발구간 NBER 침체 113주 중 8%는 모멘텀이 이미
양수로 돌아선 후반부다. 현재 모멘텀을 정직하게 재는 분류기는 그 주들을 회복기로 읽는다.
그것은 현재상태로는 옳은 판독이지만 NBER 라벨 기준으로는 미탐이다.

**대형 점프는 12국면 거리 정의에서 나온다.** 3단계 이상 점프 17건은 **전부** 대국면
2칸 이동에서 나왔고 하위국면만으로 생긴 것은 0건이다. lambda_major를 1.5에서 8.0까지
올려도 개발구간 기준 10건에서 9건으로만 줄면서 최장 연속이 34주에서 44주로 늘었다.
